# Phase 1 exploratory diagnostic decisions

No training, tuning, optimization, new predictions target, mitigation or test access. Only allowlisted train/validation data, saved original M0/M1 artifacts and validation predictions are read. Canonical identity is checked using opaque file hashing and Parquet footer metadata only. The aborted feasibility encoded file is never opened. Existing reports/test results do not determine diagnostic choices.

Signed residual is actual log1p(hours) minus prediction: positive = underprediction. Delta error = M1 absolute error minus M0 absolute error: positive = M1 worse.

A: workload aggregation overall and separately within each workload type. A workload that has multiple types can appear in multiple type scopes. Scope partitions of executions reconcile; workload counts across type scopes need not sum to the overall workload count. Frequency rankings use execution count descending and workload ID for ties. Error rankings use total signed delta error descending. Report top ceil(1%,5%,10% of scope workloads), retaining distinct rankings. Net normalized contributions divide by global net delta sum (can be negative, exceed one, or be unstable); also report contributions to global MAE difference, signed absolute-mass normalization, and shares of positive excess. No net share is treated as a probability. Error-ranked concentration is descriptive and selected on the observed error, not independent evidence.

B: all six one-way feature tables, all 15 two-way combinations, and only three prespecified three-way families: type×GPU×model, type×GPU×GPU-request, type×model×GPU-request. GPU request uses exact values (only 20–22 validation values), not outcome-chosen bins. Missing categories are explicit <MISSING>; unknown remains a real category. Flag support at >=1000 executions AND >=50 distinct workloads. Three-way tables include only cells passing that rule in at least one validation partition; coverage and omitted sparse remainder are reported so totals remain auditable. Headline cross-split comparisons require support in both partitions. No claims of causal interaction.

C: compare disjoint training and validation populations; never pair their workload identities. For each type and observed feature cell, compute execution and equal-workload duration summaries. Within each type, weights 1/n_workload_type give every workload unit mass. Let E = execution mean log-duration, W = mean of workload mean log-duration and F = E−W (frequency-duration association). The train→validation gap decomposes exactly as ΔE = ΔW + ΔF.

Further decompose ΔW using type×GPU, type×model and type×GPU×model strata: common-cell composition = (qV−qT)*(μV+μT)/2; within-cell change = (μV−μT)*(qV+qT)/2; unmatched cells contribute qV*μV−qT*μT. Here q is fractional workload membership mass in a cell divided by number of type-specific workloads, and μ is duration averaged with inverse within-type workload frequency weights. Summing all cell terms plus ΔF reproduces ΔE. Within-cell changes remain changes between distinct workload populations conditional on measured coarse features, not longitudinal change or causal conditional shift identification.

Within validation, compare top-frequency, top-positive-excess, and top-absolute-frequency-duration-tilt populations at 1%,5%,10%. Frequency-duration tilt contribution of workload w is (n_w/N−1/W)*mean_log_duration_w. Compare overlaps only within a partition and scope. Profile the top 1% selected workload populations by type×GPU×model for direct comparison of their observed characteristics. Distinguish amount of duration mass, negative/positive frequency tilt, and prediction error contribution.

Population tables include all types, type×GPU, type×model and type×GPU×model cells, both-split support flags, train/validation execution and fractional workload weights, duration summaries, validation errors and reconciled decomposition components. Overlapping stratification families must never be added together.

Uncertainty: 1000 paired workload bootstrap replicates, seed 20261027, for validation aggregate and type-specific M1−M0 error differences under both weightings. Resample workload aggregates, with execution-weighted ratio of sums. The type intervals condition on type membership; overall intervals condition on the fitted models and observed partition. No multiplicity-adjusted or confirmatory inference, and no confidence claim for error-selected top-workload rankings. Two partition results are dependent.

Verification: hash against existing manifest; verify both seeds' SHA-256 memberships at unique workload level, train/validation disjointness, row ordinal uniqueness, model hashes/features/categories/tree counts, cached prediction hash/alignment and full rowwise reproduction using original saved models. Assert aggregate historical validation MAE to 1e-10; workload and subgroup sums to 1e-9 relative tolerance; cell and weighting decompositions to 1e-10 absolute tolerance. Preserve source hashes. Synthetic checks cover signed contributions, changing cell supports, fractional multi-cell workload weights, and overlap metrics.
